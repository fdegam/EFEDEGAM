## Cómo usar esta biblioteca

- Cuando el propietario pida «referencias», «inspiración» o «inspo», devolver primero estos dos enlaces, aunque no solicite una búsqueda nueva.
- Si pide referencias para una idea concreta, partir de estas bibliotecas y explicar qué aspectos de los ejemplos pueden ayudar: composición, tipografía, navegación, interacción o movimiento.
- Distinguir los enlaces guardados de los ejemplos consultados en ese momento. No afirmar que se ha visitado una página o verificado un ejemplo si no se ha hecho.
- Añadir nuevas fuentes de confianza únicamente cuando el propietario las indique o apruebe; presentar otras fuentes como sugerencias.
- Usar las referencias para aprender e inspirarse. No asumir permiso para copiar textos, imágenes, marcas, código o datos personales.

«De confianza» expresa una preferencia editorial del propietario; no es una certificación de seguridad de esos sitios o de sus enlaces.
